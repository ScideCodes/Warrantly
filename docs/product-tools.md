# Claims, returns and family sharing

- **Claim assistant:** open a product → Support → Claim assistant. Edit the draft, select documents, then prepare an email or share a ZIP. The ZIP contains a PDF summary, the draft and original selected documents. Sharing never sends automatically.
- **Return deadline:** open a product → Returns & replacements. Choose the seller’s actual deadline with the existing calendar. Return reminders are independent of expiry reminders and arrive two days before the date at the configured fixed reminder time. The Gmail estimate remains available; it is an estimate, not a statement of eligibility.
- **Replacement history:** link an existing product or add a new replacement. Original and replacement keep separate warranty terms and documents. Links work in both directions and survive encrypted backups. Circular links are rejected. Removing links leaves both records intact.
- **Missing details:** the library menu and status row open records missing documents, serials or confirmed dates. Optional serials remain optional; nothing blocks saving.
- **Duplicates:** review suggestions from the library menu. PDF review now warns before adding matching products. Keeping both is always possible. Linked replacement chains are not suggested as duplicates.
- **Family sharing:** open the library menu or Settings → Family sharing. Select products and share a Warrantly file. The recipient uses Import shared warranties. Notes, price, order numbers and repair history are excluded by default; original documents may contain personal information. This is an explicit snapshot exchange, not live synchronization. Local replacement IDs never leave the device.

All new controls use the current iOS27 page, row, calendar, input and sheet components and support English/Hungarian and both themes. No native dependencies were added.
